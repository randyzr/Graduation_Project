## Criterios de estado

| Estado | Significado |
|---|---|
| No iniciado | No existe trabajo verificable del entregable |
| En progreso | Existe trabajo parcial y evidencia asociada |
| En revisión | El entregable está listo para recibir observaciones |
| Bloqueado | Existe un impedimento documentado |
| Completado | El criterio de aceptación fue verificado |

## Cómo revisar este espacio

1. Abrir la actualización quincenal más reciente.
2. Revisar los cambios en avance, cronograma, riesgos y retroalimentación.
3. Seguir los enlaces hacia la evidencia correspondiente.
4. Registrar nuevas observaciones en el seguimiento de retroalimentación.
