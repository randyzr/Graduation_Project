# Seguimiento de retroalimentación

## Estados

- **Recibida:** registrada, pendiente de análisis.
- **En análisis:** se está definiendo la acción apropiada.
- **En progreso:** la acción fue acordada y está en ejecución.
- **Implementada:** el cambio fue realizado y tiene evidencia.
- **Verificada:** se comprobó el resultado o fue aceptado en revisión.
- **No aplicada:** se documentó una justificación y, cuando corresponda, se acordó con las personas profesoras.
