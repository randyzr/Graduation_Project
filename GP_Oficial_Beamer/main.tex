\setrightfooter{}
\section{Definición del problema}

\begin{frame}{Planteamiento del problema}

    \begin{block}{Situación actual}
        \justifying
        Aunque existen sistemas comerciales para el control ESD en laboratorios de electrónica y
        manufactura de semiconductores, estas soluciones suelen presentar costos elevados y una
        limitada capacidad de personalización. Adicionalmente, no se identifican alternativas de
        bajo costo que integren de manera conjunta la verificación de pulseras antiestáticas, la
        identificación de usuarios, el almacenamiento de registros históricos, la generación de
        reportes y una interfaz gráfica para interactuar con el sistema.
    \end{block}

    \vspace{0.25cm}

    \begin{alertblock}{Necesidad identificada}
        \justifying
        Esta situación evidencia
        la necesidad de desarrollar una solución accesible y adaptable que permita mejorar la
        trazabilidad de las pruebas ESD en entornos de laboratorio, como el laboratorio TEM
        de Intel Costa Rica, donde se ha identificado una oportunidad de mejora en el seguimiento
        del cumplimiento de los procedimientos ESD.
    \end{alertblock}

\end{frame}

\setrightfooter{ ¿Qué se espera demostrar?}
\section{Hipótesis de solución y objetivos}

\begin{frame}{Hipótesis de solución}

    \vspace{0.35cm}

    \highlightbox{
        \centering
        \large
        Una estación inteligente de control ESD de bajo costo, basada en la integración de un 
        probador comercial de pulseras antiestáticas, identificación de usuarios mediante código 
        de barras y reconocimiento facial, monitoreo ambiental y almacenamiento local de registros, 
        mejora la trazabilidad de las pruebas ESD en entornos de laboratorio al asociar cada 
        prueba con un usuario, fecha, hora, resultado y condiciones ambientales de operación.
    }

\end{frame}

\begin{frame}{Objetivo general}

    \vspace{0.6cm}

    \begin{block}{Objetivo general del proyecto}
        \large
        \justifying
        Diseñar e implementar una estación inteligente de control ESD de bajo costo para 
        laboratorios de electrónica, integrando verificación de pulseras antiestáticas, 
        identificación de usuarios, monitoreo ambiental y almacenamiento de registros.
    \end{block}

\end{frame}

\begin{frame}{Objetivos específicos}

    \begin{block}{Objetivos específicos del proyecto}
    \small
    \begin{itemize}

        \item Integrar los módulos electrónicos requeridos para la estación inteligente de control ESD, incluyendo el 
        probador comercial, sensor ambiental, dispositivos de identificación, HMI y microcontroladores necesarios para la operación del sistema.

        \item Implementar mecanismos de identificación de usuarios mediante lectura de código de barras y reconocimiento facial.

        \item Implementar los subsistemas de interacción y monitoreo de la estación, incluyendo interfaz gráfica 
        táctil y monitoreo ambiental.

        \item Implementar almacenamiento local de registros y generación de reportes asociados a las pruebas ESD.

        \item Validar el funcionamiento del sistema mediante pruebas funcionales de los subsistemas 
        y pruebas de integración del prototipo, así como mediante pruebas de operación realizadas 
        en el laboratorio TEM de Intel Costa Rica.

    \column{0.48\textwidth}

    \begin{block}{Estrategia de validación}
        \begin{enumerate}
            \item \textbf{Pruebas funcionales}\\
            Validación individual de cada subsistema.

            \item \textbf{Pruebas de integración}\\
            Verificación de comunicación e interoperabilidad.

            \item \textbf{Pruebas operativas}\\
            Evaluación del prototipo en el laboratorio TEM.
        \end{enumerate}
    \end{block}

    \vspace{0.15cm}

    \begin{alertblock}{Criterio principal}
        El sistema debe ejecutar el flujo completo desde la identificación del usuario hasta el almacenamiento del resultado.
    \end{alertblock}

    % ========================================================
    % Right column: validation items
    % ========================================================
    \column{0.48\textwidth}

    \begin{block}{Aspectos por validar}
        \begin{itemize}
            \item Lectura de estados del probador ESD
            \item Identificación por código de barras
            \item Reconocimiento facial complementario
            \item Interfaz gráfica e instrucciones al usuario
            \item Registro de temperatura y humedad
            \item Almacenamiento local de pruebas
            \item Generación de reportes CSV
        \end{itemize}
    \end{block}
