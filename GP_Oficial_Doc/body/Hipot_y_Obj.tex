\chapter{Hipótesis y Objetivos del Proyecto}

\section{Hipótesis}

Se plantea que una estación inteligente de control ESD de bajo costo puede transformar la verificación manual 
de pulseras antiestáticas en un evento trazable y auditable mediante la integración de un probador comercial HZR-171, 
identificación de usuario, monitoreo ambiental, interfaz gráfica táctil y almacenamiento local, logrando que al 
menos el 95 \% de los ciclos completos de prueba ejecutados mediante el prototipo generen registros completos 
compuestos por usuario, fecha, hora, resultado ESD, temperatura y humedad relativa, con un costo 
estimado de materiales inferior a 350 USD.

\section{Objetivos}

        \subsection{Objetivo General}
            Diseñar e implementar un sistema inteligente de control ESD de bajo costo para 
            laboratorios de electrónica, integrando verificación de pulseras antiestáticas, 
            identificación de usuarios, monitoreo ambiental y almacenamiento de registros.


        \subsection{Objetivos Específicos}
                
        \begin{itemize}

        \item Integrar los módulos electrónicos requeridos para el sistema inteligente de control ESD, incluyendo el 
        probador comercial, sensor ambiental, dispositivos de identificación, ESP32 HMI
         y microcontroladores necesarios para la operación del sistema.

        \item Implementar mecanismos de identificación de usuarios mediante lectura de código de barras y reconocimiento facial.

        \item Implementar los subsistemas de interacción y monitoreo de la estación, incluyendo interfaz gráfica 
        táctil y monitoreo ambiental.

        \item Implementar almacenamiento local de registros y generación de reportes asociados a las pruebas ESD.

        \item Validar el funcionamiento del sistema mediante pruebas funcionales de los subsistemas 
        y pruebas de integración del prototipo, así como mediante pruebas de operación realizadas 
        en el laboratorio TEM de Intel Costa Rica.

        \end{itemize}

\section{Alcances y Limitaciones del Proyecto}

\subsection{Alcances}

El proyecto contempla el diseño e implementación de una estación inteligente de control ESD de bajo costo para entornos de laboratorio, integrando diferentes subsistemas orientados a mejorar la trazabilidad y el cumplimiento de procedimientos de protección contra descargas electrostáticas.

Dentro de los alcances del proyecto se consideran los siguientes:

\begin{itemize}
\item Integración de un probador comercial de pulseras antiestáticas HZR-171 como subsistema principal de verificación ESD.
\item Identificación de usuarios mediante lectura de código de barras.
\item Implementación de reconocimiento facial como mecanismo complementario de identificación.
\item Monitoreo de temperatura y humedad relativa mediante sensores ambientales.
\item Desarrollo de una interfaz gráfica táctil para la interacción con el usuario y la visualización de información del sistema.
\item Almacenamiento local de registros asociados a pruebas ESD, identificación de usuarios, variables ambientales.
\item Generación de reportes históricos a partir de la información almacenada localmente.
\item Diseño CAD y construcción de una estructura física que facilite la integración y operación de los subsistemas electrónicos.
\item Validación funcional de los subsistemas desarrollados y validación operativa del prototipo en el laboratorio TEM de Intel Costa Rica.
\end{itemize}

\subsection{Limitaciones}

Las principales limitaciones consideradas para el desarrollo del proyecto son las siguientes:

\begin{itemize}
\item El sistema utilizará un probador comercial de pulseras antiestáticas como mecanismo principal de verificación ESD.
\item El rango de operación y los criterios de aprobación o rechazo de las pruebas ESD estarán limitados por las especificaciones del probador HZR-171.
\item El sistema estará orientado a la verificación de pulseras antiestáticas y no incluirá la evaluación de otros elementos de control ESD.
\item El reconocimiento facial podrá verse afectado por condiciones de iluminación, posición del usuario y calidad de las imágenes capturadas.
\item Los registros generados por el sistema serán almacenados localmente y no se contempla la integración con bases de datos corporativas o servicios en la nube.
\item El sistema no contempla integración con sistemas institucionales de control de acceso o gestión de personal.
\item La validación operativa se realizará mediante pruebas en el laboratorio TEM de Intel Costa Rica bajo las condiciones y recursos disponibles durante el periodo de ejecución del proyecto.
\item El prototipo desarrollado tendrá fines académicos y de investigación, por lo que no pretende sustituir sistemas comerciales certificados para control ESD.
\item El diseño de un circuito propio para la medición de resistencia cuerpo-tierra no forma parte del alcance obligatorio del proyecto y podrá considerarse como trabajo complementario si el tiempo y los recursos disponibles lo permiten.
\item No se solicitará una base de datos con las identificaciones empresariales de cada trabajador que haga uso del laboratorio de Intel TEM Costa Rica, por lo que cada usuario que haga uso por primera vez del prototipo debe de registrar su nombre y identificación empresarial.
\item La detección facial de cada usuario no será obligatoria y se le solicitará permiso a cada usuario nuevo para poder registrarla en el sistema.
\item Los datos empresariales que haga uso el prototipo como el registro de los usuarios con sus identificaciones y nombres no se compartirán en el reporte final debido a políticas de privacidad.
\item El prototipo no detectará la cantidad de cargas electroestáticas, campo electroestático o tensión eléctrica almacenada en el usuario.
\end{itemize}
