\chapter*{Resumen}
\addcontentsline{toc}{chapter}{Resumen}

Este proyecto propone el diseño de un sistema inteligente de bajo costo para el 
control de descargas electrostáticas (ESD) en laboratorios de electrónica y entornos 
de manufactura de dispositivos semiconductores. La solución integra medición de resistencia 
cuerpo--tierra, identificación de usuario, interfaz gráfica, monitoreo ambiental, registro de pruebas, generación de reportes
y detección de usuario. El sistema busca ofrecer una alternativa accesible y personalizable frente a 
soluciones comerciales de mayor costo, manteniendo criterios de calidad en la medición de alta impedancia 
y trazabilidad del cumplimiento ESD.

\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This project proposes the design of a low-cost smart system for electrostatic discharge (ESD) 
control in electronics laboratories and semiconductor manufacturing environments. The proposed 
solution integrates body-to-ground resistance measurement, user identification, graphical interface, 
environmental monitoring, test logging, report generation and user detection. The system aims to provide an accessible 
and customizable alternative to higher-cost commercial solutions while maintaining quality criteria for 
high-impedance measurement and ESD compliance traceability.
